# Project Case Study: Web Archiving & Capturing Grassroots Ephemera

## Overview

This project collection explores the preservation of born-digital materials through web archiving workflows. It focuses on capturing ephemeral online resources, community documentation, and dynamic websites that are vulnerable to disappearance due to link rot, platform changes, organizational transitions, or limited digital infrastructure.

Grassroots organizations, community groups, and independent creators frequently rely on web-based platforms as their primary method of communication and documentation. These materials often represent significant historical records but may not be preserved through traditional archival workflows.

---

## Objectives

The goal of these case studies is to demonstrate practical approaches for:

- Capturing dynamic web content using web harvesting tools
- Preserving interactive websites and digital ephemera
- Documenting appraisal and selection decisions
- Creating metadata and preservation documentation
- Addressing rights, ethics, and access considerations in web archiving

---

## Tools & Standards Used

* **Capture Tools:** ArchiveWeb.page / Webrecorder tools
* **Storage Format:** WARC (Web ARChive) ISO standard file format (ISO 28500)
* **Replay Tools:** ReplayWeb.page
* **Metadata & Documentation:** CSV metadata records, Markdown documentation, preservation notes

---

## Web Archiving Workflow

Each case study follows a documented preservation workflow:

1. **Appraisal & Selection**
   - Define collection scope and selection criteria
   - Identify digital materials with preservation value

2. **Seed Definition**
   - Identify target URLs
   - Determine capture scope and navigation boundaries

3. **Web Capture**
   - Capture websites and digital materials using web archiving tools
   - Preserve interactive elements, linked resources, and embedded content when possible

4. **WARC Preservation**
   - Export captured content into WARC format
   - Maintain original web resources, HTTP metadata, and timestamps

5. **Documentation & Access**
   - Create descriptive metadata
   - Document preservation decisions
   - Provide replay access when appropriate

## Archival Reflection

Web archiving has become an essential component of contemporary archival practice. Community histories are increasingly created, shared, and maintained online, yet digital materials remain vulnerable to disappearance.

Preserving these resources requires both technical knowledge and archival judgment: determining what should be captured, how it should be preserved, and how it can remain accessible while respecting creator rights and community context.
