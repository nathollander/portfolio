# Project Case Study: Web Archiving & Capturing Grassroots Ephemera

## Objective
To capture, preserve, and render high-fidelity, interactive snapshots of ephemeral community websites and online mutual aid directories using industry-standard web harvesting protocols.

## Tools & Standards Used
* **Capture Engine:** ArchiveWeb.page (by Webrecorder)
* **Storage Format:** WARC (Web ARChive) ISO standard file format (ISO 28500)
* **Replay Engine:** ReplayWeb.page 

## The Scenario
A local grassroots LGBTQ+ mutual aid group organizes entirely online through a self-hosted blog and a fast-moving community bulletin page. Because grassroots groups frequently shut down or lose funding, their entire digital footprint is at extreme risk of link rot and sudden disappearance. Standard screenshots fail to capture the interactive drop-down menus, resource links, and embedded documents.

---

## The Web Archiving Workflow

To successfully capture this dynamic content, I utilized a client-side high-fidelity web archiving approach:

1. **Seed Definition:** Identified core URLs and mapped out the navigation scope (how deep into sub-pages the crawler should venture).
2. **Interactive Ingest (ArchiveWeb.page):** Rather than using a blind automated script, I navigated the site actively. This allowed the browser-based crawler to record network traffic generated by JavaScript elements, embedded PDF newsletters, and interactive menus.
3. **WARC Export:** Compiled the captured data into a single `.warc` file, packaging the original HTTP request/response headers, timestamps, and digital assets into a tamper-proof container.

---

## Live Replay Implementation

To make the file accessible to researchers without forcing them to download raw technical data, I implemented **ReplayWeb.page** to render the static WARC file directly in the browser interface.

```javascript
// Conceptual rendering block for embedding web archive payloads into a digital exhibit
<script src="https://unpkg.com"></script>
<replay-web-page 
  src="assets/warc/local-lgbtq-mutual-aid-2026.warc" 
  url="https://example-mutual-aid-group.org">
</replay-web-page>
```

---

## 💡 Archival Reflection
Modern queer and marginalized community organizing happens primarily on social media and dynamic web platforms. If archivists rely solely on traditional paper-collecting mandates, decades of local history will be wiped out by server expiration or link rot. Knowing how to capture high-fidelity WARC files ensures that community archives can capture history in real-time, preserving the authentic digital experience for future researchers.
