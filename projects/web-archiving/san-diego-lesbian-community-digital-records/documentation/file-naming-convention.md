# File Naming Convention

## Overview

All preserved digital objects in the San Diego Lesbian Community Digital Records, Spring–Summer 2026 collection are assigned unique identifiers to support file management, metadata tracking, and preservation workflows.

## Identifier Format

Identifiers follow the format:

SDLD-###

Where:

- SDLD = San Diego Lesbian Digital Records
- ### = sequential item number

## File Naming Format

Preserved files follow the structure:

`identifier_creator-description.extension`
