# Preservation Plan

## Collection

San Diego Lesbian Community Digital Records, Spring–Summer 2026

## Preservation Approach

This project preserves publicly accessible born-digital records documenting contemporary lesbian community life in San Diego through web capture, file-level preservation, metadata creation, and fixity verification.

## File Formats

Preserved materials may include:

- PNG images
- HTML webpages
- WARC files
- audiovisual files
- interactive digital publications

## Capture Methods

Different record types require different preservation methods:

- Web content → ArchiveWeb.page WARC capture
- Digital images → direct file preservation
- Social media content → web capture and descriptive metadata

## Fixity

SHA-256 checksums are generated for preserved files to document file integrity and detect future changes.

## Access

Preserved materials are maintained as a technical portfolio demonstrating digital preservation workflows. Rights remain with original creators and organizations.
