# Preservation Plan

## Collection

**San Diego Lesbian Community Digital Records, Spring–Summer 2026**

## Preservation Approach

This project preserves publicly accessible born-digital records documenting contemporary lesbian community life in San Diego through a combination of archival appraisal, web capture, file preservation, metadata creation, fixity verification, and replay validation.

The preservation workflow follows a staged approach in which digital materials are identified and appraised, captured using appropriate preservation methods, described through structured metadata, and verified to ensure successful preservation.

## File Formats

Preserved materials may include:

* PNG images
* HTML webpages
* WARC files (ISO 28500:2017)
* audiovisual records captured through web archives
* interactive digital publications and associated web resources

File formats were selected based on the nature of the original digital resource and the goal of preserving both content and contextual information.

## Capture Methods

Different record types require different preservation approaches:

* **Web content:** Captured using ArchiveWeb.page in WARC format to preserve webpage structure, resources, and embedded metadata.
* **Social media content:** Captured through web archiving workflows with descriptive metadata documenting platform, creator, and community context.
* **Digital images:** Preserved as original downloaded files with associated descriptive metadata.
* **Interactive publications:** Captured through web archiving to preserve both interface elements and underlying digital resources when available.

## Metadata Creation

Descriptive and administrative metadata are created for each preserved item, including:

* identifier
* title
* creator
* material type
* original URL
* date identified
* event or publication date
* location
* file format
* appraisal decision
* preservation priority
* notes regarding significance and context

Metadata supports discovery, management, and future interpretation of preserved digital records.

## Fixity

SHA-256 checksums are generated for preserved files to document file integrity and support future fixity verification. Checksum values are maintained in a checksum manifest associated with the collection.

## Validation

WARC captures are validated through replay testing in ReplayWeb.page to confirm successful loading of archived resources and assess the extent to which original digital experiences were preserved.

Validation includes:

* successful WARC loading
* replay accessibility
* verification of captured content and resources
* documentation of preservation limitations

## Storage and Organization

Preserved materials are organized according to a structured archival directory system separating appraisal documentation, captured resources, metadata, preservation records, rights documentation, and collection-level documentation.

## Access and Rights

Preserved materials are maintained as a technical portfolio demonstrating digital preservation workflows and archival decision-making.

Materials were collected from publicly accessible sources. Copyright and intellectual property rights remain with original creators, organizations, and platforms. Preservation does not transfer ownership or grant publication rights. Any future access, reuse, or redistribution should consider applicable rights restrictions and creator intent.
