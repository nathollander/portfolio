# San Diego Lesbian Community Event Ephemera, Summer 2026

## Project Overview

This case study documents the appraisal, capture, and preservation of publicly accessible born-digital ephemera related to lesbian community events in San Diego, California during Summer 2026.

## Project Status

In progress.

## Preservation Focus

- Web archiving
- Born-digital ephemera
- Metadata creation
- Digital preservation workflows
- Rights and ethical considerations
