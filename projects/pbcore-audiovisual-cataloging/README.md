# Audiovisual Cataloging using PBCore

## Overview

This project collection demonstrates audiovisual metadata workflows using the PBCore (Public Broadcasting Metadata Dictionary Project) standard. It explores the description, documentation, and management of audiovisual materials through structured metadata, technical characterization, and preservation documentation.

Audiovisual materials require specialized metadata to capture both their technical properties and cultural context. Unlike traditional textual records, moving image and sound recordings require documentation of format, carrier information, digital instantiation, technical characteristics, contributors, and rights considerations to support long-term stewardship and discovery.

---

## Objectives

These case studies demonstrate practical approaches to:

- Creating structured audiovisual metadata records using PBCore
- Documenting relationships between original physical carriers and digital derivatives
- Applying descriptive, technical, and administrative metadata practices
- Incorporating community-centered subject terminology for improved discovery
- Recording rights, access, and preservation considerations for audiovisual materials

## Standards & Tools Used

**Metadata Standard:**
- PBCore 2.1

**Controlled Vocabularies:**
- Homosaurus Linked Data Vocabulary
- Local descriptive terminology

**Technical Characterization:**
- FFprobe / FFmpeg

**Documentation Formats:**
- XML metadata records
- Markdown preservation documentation
- Technical metadata reports

---

## Audiovisual Cataloging Workflow

Each case study follows a documented metadata workflow:

1. **Source Record Analysis**
   - Review existing repository description and provenance information
   - Identify descriptive, administrative, and technical metadata elements

2. **Metadata Mapping**
   - Map existing descriptive information to PBCore elements
   - Identify appropriate contributors, subjects, instantiations, and rights fields

3. **Technical Characterization**
   - Analyze digital audiovisual derivatives
   - Document file format, codecs, duration, resolution, and technical properties

4. **PBCore Record Creation**
   - Create structured XML metadata records
   - Document physical and digital instantiations separately

5. **Preservation Documentation**
   - Record workflow decisions, rights considerations, and preservation notes
