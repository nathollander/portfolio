# Workflow Notes

## Collection Development

The collection was assembled as a small digital exhibit prototype exploring lesbian print culture in Los Angeles from 1947–1999.

## Workflow

1. Created collection inventory spreadsheet
2. Prepared digital object filenames
3. Uploaded digital objects into Omeka Classic
4. Applied Dublin Core metadata
5. Organized items into collections
6. Created interpretive exhibit pages using Exhibit Builder
7. Tested public-facing exhibit display

## Technical Environment

The exhibit was developed locally using MAMP, with Omeka Classic running through an Apache/PHP/MySQL environment.
