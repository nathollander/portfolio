# Metadata Notes

## Descriptive Metadata

Items were described using the Dublin Core metadata fields available in Omeka Classic. Metadata was created at the item level to support discovery, contextualization, and connection to original archival sources.

## Item Types

Item types were selected based on the nature of the original archival object. Textual publications, including newspapers, newsletters, and zines, were categorized according to their textual nature even when represented through digital image surrogates.

## Subject Terms

Subject terms were created to support discovery and reflect the historical context of lesbian print culture, feminist publishing, community spaces, and Southern California lesbian organizing. Terms were selected using descriptive language appropriate for the collection context.
