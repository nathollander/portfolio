# SCLAP Omeka Digital Exhibit Prototype Walkthrough

## Overview

This folder contains documentation for an Omeka Classic digital exhibit prototype created as part of my work developing the **Southern California Lesbian Archives Project (SCLAP)**.

The public-facing SCLAP project is hosted separately as a digital public history website. This Omeka installation serves as a technical demonstration of the digital collections workflow behind building an archival exhibit, including local development, database configuration, metadata creation, collection management, and exhibit construction.

## Project Description

The exhibit, **"Lesbian Print Culture in Los Angeles, 1947–1999,"** explores how lesbian communities created and circulated their own publications, newsletters, advertisements, zines, and other forms of community print culture outside traditional publishing systems.

Using Omeka Classic, I created a small digital collection that demonstrates how archival materials can be described, organized, and interpreted through a digital collections platform.

## Technical Workflow Demonstrated

The walkthrough video demonstrates:

- Setting up a local Omeka Classic installation using **MAMP**
- Configuring the Apache web server, PHP environment, and MySQL database
- Managing Omeka files and installation structure
- Working with the Omeka administrative interface
- Creating collections and item records
- Applying Dublin Core metadata
- Managing digital objects and archival surrogates
- Building a public-facing digital exhibit using Exhibit Builder

## Tools & Technologies

- **Omeka Classic** — digital collections management and exhibit platform
- **MAMP** — local development environment
- **Apache** — web server
- **PHP** — server-side scripting environment
- **MySQL** — relational database management system
- **phpMyAdmin** — database administration interface
- **Dublin Core Metadata Element Set** — descriptive metadata framework
- **Exhibit Builder Plugin** — Omeka exhibit creation tool

## Metadata & Description Practices

Item records were created using Dublin Core metadata fields including:

- Title
- Subject
- Description
- Source
- Date
- Format
- Identifier
- Coverage
- Rights information

Metadata decisions were made with attention to archival context, discoverability, and the relationship between original physical materials and their digital representations.
